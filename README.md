# miniguia-notebooklm-estudos-ia
Uso de IA com NotebookLM para aprendizado em Python e QA, com automação de testes usando Selenium.

# 📘 IA como Ferramenta de Aprendizado: Caderno Temático com NotebookLM

## 👨‍💻 Sobre o Projeto

Este repositório documenta a aplicação prática de Inteligência Artificial, utilizando o NotebookLM, como ferramenta de apoio ao aprendizado em tecnologia, com foco em **Python e Testes de Software (QA)**.

---

## 🎯 Objetivos

- Utilizar IA para potencializar o aprendizado técnico
- Aprender Testes de Software (QA)
- Aplicar Python na automação de testes
- Criar material para revisão
- Desenvolver pensamento crítico com IA
